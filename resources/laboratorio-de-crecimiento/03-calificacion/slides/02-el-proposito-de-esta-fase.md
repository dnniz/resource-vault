# El propósito de esta fase

Acá se filtra el ruido. No se vende: **se decide si el lead merece tiempo de un humano senior.**

El mismo síntoma, leído como diagnóstico:

| Síntoma | Qué revisar primero |
|---|---|
| Pocos mensajes | problema de volumen |
| Muchos mensajes y pocas respuestas | targeting o apertura |
| Muchas respuestas pero pocas calificadas | ICP o preguntas |
| Interesados que desaparecen | seguimiento o siguiente paso |

Lee la tabla en orden. No diagnostiques ICP si antes no hubo respuestas humanas.
