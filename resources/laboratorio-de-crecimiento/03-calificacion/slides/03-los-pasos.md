# Los siete pasos

1. Primer contacto: saludo, presentación, mensaje de plantilla v.X.
2. Preguntas de discovery inicial: set de **4 a 7** preguntas estandarizadas.
3. Validación de fit contra criterios duros: ICP de tamaño, mercado, situación, autoridad.
4. Identificación de objeciones tempranas: precio, timing, autoridad, escepticismo.
5. Decisión: **avanza** a discovery / **espera** / **se descalifica** / **se nutre**.
6. Si avanza: se agenda strategy call **y** se envía contexto previo al rep senior.
7. Si se descalifica: motivo cerrado **y** fecha de re-engage si aplica.
