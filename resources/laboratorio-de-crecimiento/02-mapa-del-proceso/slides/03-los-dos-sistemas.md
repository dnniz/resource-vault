# Los dos sistemas componen un loop

## El experimento y la entrega forman un ciclo

```text
EXPERIMENTO SEMANAL  →  identifica la fuga  →  formula hipótesis
      ↑                                            ↓
  convierte                        interviene UNA variable → ejecuta
      ↑                                            ↓
     documenta ← learning ← registra ← entrega (con evidencia)
```

**Principio operativo:** un negocio no se administra como una lista de tareas. Se
administra como un sistema de entradas, transformación, salidas y retroalimentación.

La cadena completa: Atracción → Conversaciones → Conversión → Onboarding →
Delivery → **Resultado** → Retención → **Referidos y evidencia**.
