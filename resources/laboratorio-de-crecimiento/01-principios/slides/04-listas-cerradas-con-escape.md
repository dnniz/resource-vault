# Listas cerradas con escape

Fuente, canal, objeción, motivo de pérdida: **todo** se elige de una lista cerrada.

- Cada campo enum acepta **«otro»** con texto libre.
- Ese texto libre va a una **cola de revisión**, no al análisis directo.
- **Lo que se repite, se gradúa a opción nueva.**

## Por qué esto habilita el análisis

No podés agrupar lo que nunca agrupaste. Sin listas cerradas, cada motivo de
descalificación es una frase distinta y el dashboard nunca puede sumar.
