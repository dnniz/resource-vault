# Título de una slide de contenido

Párrafo corto de entrada que encuadre lo que viene.

- Lista de pasos o ideas clave.
- **Negrita** para lo que hay que recordar; `código` para comandos literales.
- Nota manuscrita del autor: > ✎ _texto_
- Caja destacada: - **Título** — descripción

Tabla, si ayuda:

| Columna | Contenido |
|---|---|
| `a` | valor |

Código, con fence. Si el código contiene ``` , usa ~~~ en su lugar:

```bash
comando --opcion valor
```

## Subtítulo de sección (opcional)

Lo que sigue aparece como un bloque más en la slide.
