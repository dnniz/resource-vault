## El segundo cliente rompió el sistema

Casi al mismo tiempo configuraba Haiku para un segundo cliente y notó algo que
no había visto con el primero:

> "Las reglas de negocio de cada rubro son mundos diferentes."

Con el primer cliente se había armado un **onboarding semi-estático**: el prompt
del agente se configuraba una vez y listo. Al intentar adaptarlo a otro rubro,
**todo se rompía**:

- Las preguntas eran otras.
- Los flujos de venta eran distintos.
- Las respuestas esperadas no encajaban.

Así que rehizo el onboarding para que fuera casi **100% dinámico** si el cliente
lo necesita. Adaptar un producto a un rubro no es cambiar el texto del bot: es
aprender reglas de negocio que ni sabías que existían. Eso toma **tiempo,
conversación y humildad** para aceptar que tu producto genérico no cubre lo que
creías.
