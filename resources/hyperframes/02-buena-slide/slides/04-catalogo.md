# Paso 3: buscá el componente antes de dibujarlo

El catálogo tiene alrededor de 400 bloques listos. Dibujar a mano lo que ya
existe es trabajo perdido y peor resultado.

- **La búsqueda no necesita nada**: sin proyecto, sin cuenta, sin instalar. Se
  puede correr desde cualquier directorio
- **Nombrar el bloque en el prompt fija la técnica**: no es un drop-in, es un
  punto de partida que el agente adapta a tu contenido
- **Cuando el nombre del bloque puede fallar, nombralo siempre en el prompt**

| Si la slide afirma… | Bloque |
|---|---|
| Una magnitud que se compara | `data-chart`, `animated-bar-chart` |
| Una ranking que se invierte | `bar-chart-race` |
| Un proceso con decisiones | `flowchart` |
| Cómo se ve la interfaz | `browser-device-stage` |
| Dónde pasa algo | `world-map`, `us-map-bubble` |
| Cómo se ejecuta esto | `code-terminal-run` |
| Una frase que hay que oír | `caption-highlight` |

- **Inventario completo** en la parte 5 del curso
- **Costo de no buscar**: el agente lo va a buscar igual, pero si no lo nombrás,
  elige por vos y puede elegir mal
