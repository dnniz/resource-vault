# Cómo se construye una buena slide

## El visual no decora: demuestra

Si la slide dice "el churn bajó 40%", mostrar un gráfico no la hace más
atractiva. La hace **verificable**.

- **Slide sin visual útil**: el texto afirma, vos confiás
- **Slide con visual útil**: el texto afirma, el visual lo prueba

- **Animación decorativa**: el texto entra con rebote. No agrega información
- **Animación funcional**: el gráfico crece hasta el valor final. Agrega información

**Regla de la casa:** si sacar la animación no cambia lo que se entiende, la
animación no debería estar.
